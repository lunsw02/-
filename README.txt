김도훈의 휴대폰 - 다시, 너에게

1. index.html을 브라우저에서 열면 바로 플레이할 수 있습니다.
2. GitHub Pages 공개: 새 public repository를 만들고 ZIP을 압축 해제한 파일(index.html 및 assets 폴더)을 루트에 업로드하세요.
3. Repository Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. 배포 주소는 https://사용자명.github.io/저장소명/ 입니다.

기능: 잠금화면, 홈, 카카오톡형 대화, 3단계 선택지, 배드엔딩 3개/해피엔딩 1개, 엔딩 수집, 메모, 녹음 텍스트 연출, 전화 텍스트 연출, 사진, 가상 검색 기록, 로컬 저장.
주의: 실제 전화 발신이나 오디오 녹음이 아닙니다. 모든 내용은 팬픽용 가상 연출입니다.
